# Programming Notes & Quiz System

A full-stack web application developed using **PHP** and **MySQL** that helps students access programming study materials, attempt online quizzes, and track their learning progress. The system also includes an admin panel for managing users, notes, quizzes, and other content.

I built this project as my **BCA Final Year Project** to strengthen my full-stack web development skills and gain hands-on experience in developing database-driven web applications.

---

## Features

### Student Module

- User Registration and Login
- Access programming notes
- Download study materials
- Attempt online quizzes
- View quiz results
- Submit feedback
- Change password
- User activity tracking

### Admin Module

- Secure Admin Dashboard
- Manage users
- Upload and manage programming notes
- Monitor user activities
- Manage quizzes and feedback
- Database management using MySQL

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/Rohit-walvekar/programming-notes-quiz-system.git
```

### 2. Move the project folder

Copy the project folder into the **htdocs** directory of your XAMPP installation.

### 3. Import the database

- Open **phpMyAdmin**
- Create a new database
- Import the provided **DB.sql** file

### 4. Start Apache and MySQL

Launch both services using the **XAMPP Control Panel**.

### 5. Run the application

Open your browser and visit:

```text
http://localhost/miniProject/home.php
```
